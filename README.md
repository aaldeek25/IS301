## Why Version Control Matters

Version control functions as both a time machine and a safety net. Rather than storing files called final_v2_REALLYFINAL.docx, Git logs each modification along with an explanation.

## Core Commands I Should Know

- `git init` creates a new repository
- `git clone` copies an existing repository to your computer
- `git status` shows which files have changed
- `git add` stages changes
- `git commit` saves a snapshot
- `git push` sends commits to the remote repository
- `git pull` brings down the latest changes from the remote
- `git log` shows the history of commits
- `git branch` lists or creates branches
- `git diff` shows exactly what changed in your files
